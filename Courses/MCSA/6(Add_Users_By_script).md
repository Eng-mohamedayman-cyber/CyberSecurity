# 🤖 Bulk User Creation in Active Directory Using AI Scripts

Instead of manually creating dozens or hundreds of user accounts one by one inside Active Directory Users and Computers (ADUC), system administrators can leverage Artificial Intelligence (like Microsoft Copilot) to generate a customized automation script. This approach completes hours of repetitive data-entry work in just under 30 seconds.

---

## 1️⃣ Step 1: Prompting the AI Model (Microsoft Copilot)

You can communicate with the AI using normal conversational language (even in your local Arabic dialect) without needing perfect English proficiency.
The administrative prompt should include:

* **The Goal**: Request an automation script to insert multiple users simultaneously.
* **The Source Data**: Mention that the data will come from a CSV file.
* **Target Container (OU)**: Provide the exact destination Organizational Unit name (e.g., CRM).
* **Domain Environment**: Provide the FQDN of your local domain (e.g., test.local).
* **Required Attributes**: Ask for essential user columns like First Name, Last Name, Full Name, User Logon Name, and Password.
* **Sample Data**: Ask the AI to populate the CSV with sample placeholder accounts (e.g., 5 random users) to test the mechanism.

```text
محتاج اعمل إضافة لمجموعة مستخدمين علي Active Directory باستخدام ملف CSV
 و الدومين اسمه Test.local و ال OU اسمها CRM
 ال csv يكون فيه First Name , Last Name , Full Name , User login Name , password
اديني ال CSV كامل و يكون فيه بيانات خمس موظفين بشكل عشوائي و الباور شيل سكريبت
```
---

## 2️⃣ Step 2: Preparing the CSV Data File

The AI will generate two outputs: a dataset grid and a script code block.

* **Creating the File**: Copy the user data generated by the AI, paste it into a blank Notepad text document, and save it using the extension .csv (e.g., users.csv).
* **Modifying Accounts**: You can open this file using Notepad or Microsoft Excel to easily add, remove, or modify your real company employee lists and initial passwords.
* **Deployment**: Transfer this finished .csv file directly onto your Windows Server.

---

## 3️⃣ Step 3: Executing the PowerShell Script

Active Directory utilizes Windows PowerShell ISE to run administrative scripts safely.

```text
# مسار ملف الـ CSV
$csvPath = "C:\path\to\your\users.csv"

# تحديد مكان الـ OU والدومين المستهدف
$targetOU = "OU=CRM,DC=Test,DC=local"

# استيراد البيانات من الملف
$users = Import-Csv -Path $csvPath

foreach ($user in $users) {
    # تحويل كلمة المرور إلى نص مشفر وآمن
    $securePassword = ConvertTo-SecureString $user.Password -AsPlainText -Force

    # تجهيز المعاملات لإنشاء المستخدم
    $userParams = @{
        Name                  = $user.FullName
        GivenName             = $user.FirstName
        Surname               = $user.LastName
        UserPrincipalName     = $user.UserLoginName
        SamAccountName        = ($user.UserLoginName -split "@")[0] # استخراج اسم المستخدم قبل علامة @
        AccountPassword       = $securePassword
        Path                  = $targetOU
        Enabled               = $true # تفعيل الحساب مباشرة
        ChangePasswordAtLogon = $false # عدم إلزام الموظف بتغيير الباسورد عند أول تسجيل دخول
    }

    try {
        # إنشاء المستخدم في الـ Active Directory
        New-ADUser @userParams
        Write-Host "تم إنشاء المستخدم بنجاح: $($user.FullName)" -ForegroundColor Green
    }
    catch {
        Write-Host "فشل إنشاء المستخدم: $($user.FullName). الخطأ: $_" -ForegroundColor Red
    }
}

```

1. **Launch Environment**: Search for Windows PowerShell ISE on the server, right-click, and select Run as administrator.
2. **Import Script**: Copy the automation script provided by the AI and paste it into the script pane of the console.
3. **Update Path Variable**: Modify the file path variable inside the code block to point directly to where you saved your CSV file (e.g., changing it to match your folder destination).
4. **Run Code**: Click the Run Script button (or press F5). The script will process the CSV row-by-row and map each account to Active Directory.

---

## 4️⃣ Step 4: Verification

* Open your Active Directory Users and Computers console.
* Navigate to your designated Organizational Unit (CRM).
* Right-click and choose Refresh. You will instantly see all the user accounts created with all their attributes mapped correctly.
